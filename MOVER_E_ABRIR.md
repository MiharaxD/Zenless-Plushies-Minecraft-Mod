# ZZZ Plushies: pasta pronta para mover

Mova **esta pasta inteira** para o destino desejado. A estrutura foi mantida para que o gerador encontre as skins por caminho relativo:

```text
ZZZ-Plushies-Para-Mover/
├── zzz-plushies/             projeto Forge, fontes, recursos, documentação, builds e versões
├── assets/zzz-plushie-skins/ skins originais selecionadas e manifesto
└── references/              áudio, vídeo, modelo e imagens fornecidos como referência
```

Para trabalhar, abra `zzz-plushies/` na IDE. Comece por `zzz-plushies/docs/INDEX.md`; as instruções para futuras alterações estão em `zzz-plushies/AGENTS.md`. Para instalar o mod pronto, use `zzz-plushies/output/zzz-plushies-forge-1.20.1-1.8.1.jar` em Minecraft 1.20.1 com Forge 47.3.0. Para compilar após a mudança, configure Java 17 e rode `gradlew.bat build` dentro de `zzz-plushies/`; o wrapper pode baixar dependências.

Esta é uma **cópia**. Os arquivos originais em `C:/Users/YURI/Documents/MODSGPT/zzz-plushies/` e `assets/zzz-plushie-skins/` foram preservados. Se editar esta cópia depois da mudança, ela e o original poderão divergir; escolha uma como projeto de trabalho.
